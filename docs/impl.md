# PHP Stubs Implementation Notes

## Libraries

- **[SnakeYAML]** `org.yaml:snakeyaml:2.2` -- YAML parsing.

## APIs

- **[SnakeYAML]** `Yaml().load<Any>(reader)` -- returns `ArrayList` for YAML lists, `LinkedHashMap` for maps. Cast required.
- **[Collections]** `Collections.unmodifiableMap(map)` -- runtime read-only enforcement. Wraps without copying.
- **[Class]** `Class.getResourceAsStream(path)` -- loads YAML files and `index.txt` from classpath `stubs/` directory.

## Developer Instructions

- YAML files organized in subdirectories under `stubs/`: `standard/`, `database/`, `network/`, `text/`, `crypto/`, `file/`, `xml/`, `image/`, `system/`, `misc/`. `core.yaml` at the root.
- `index.txt` auto-generated by Gradle `processResources` -- not manually maintained. Adding a new YAML file requires only placing it in the correct directory.
- Extension name derived from filename with `_\d+$` suffix stripped (e.g., `standard_1.yaml` -> `standard`).
- SnakeYAML parses bare `true`/`false`/`null`/`on`/`off` as Java Boolean/null -- quote these values in YAML.
- `tag` field on every YAML entry determines parsing schema. Unknown tags rejected with `StubIndexInvalidException`.
- Duplicate names within the same tag across files: last-loaded file wins.
- `flowsToReturn` is optional. Absent = pure computation (return value does not contain parameter data).
- Performance tests excluded by default. Run with `./gradlew test -Pperformance`.

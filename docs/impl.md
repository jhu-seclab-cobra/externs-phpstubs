# PHP Stubs Implementation Notes

## APIs

- **[SnakeYAML]** `Yaml().load<Any>(reader)` -- returns `ArrayList` for YAML lists, `LinkedHashMap` for maps. Cast required.
- **[Collections]** `Collections.unmodifiableMap(map)` -- runtime read-only enforcement. Wraps without copying.
- **[Class]** `Class.getResourceAsStream(path)` -- loads YAML files and `index.txt` from classpath `stubs/` directory.

## Libraries

- **[SnakeYAML]** `org.yaml:snakeyaml:2.2` -- YAML parsing.

## Developer Instructions

- File organization of `stubs/` (category subdirectories, `core.yaml`, extension-name derivation): see [design.md](design.md) File Organization.
- `index.txt` is auto-generated by Gradle `processResources` -- not manually maintained. Adding a new YAML file requires only placing it in the correct directory.
- SnakeYAML parses bare `true`/`false`/`null`/`on`/`off` as Java Boolean/null -- quote these values in YAML.
- `tag` field on every YAML entry determines parsing schema. Unknown tags rejected with `StubIndexInvalidException`.
- Duplicate names within the same tag are corpus defects: loading fails with `StubIndexInvalidException` naming the key and both defining files.
- `flowsToReturn` is optional. Absent = pure computation (return value does not contain parameter data).
- Performance tests excluded by default. Run with `./gradlew test -Pperformance`.

## Design-Specific

### Upstream extraction (phpstorm-stubs -> stubs/)

- Script not yet written. Will use `nikic/php-parser` + Psalm stubs.
- Input: `JetBrains/phpstorm-stubs` (signatures) + `vimeo/psalm` (`@psalm-flow` annotations).
- Output: `stubs/**/*.yaml` files organized by category subdirectory.

### Declaration DSL conversion (stubs/ -> models/)

- `tools/convert_stubs.py` converts tag-based `stubs/**/*.yaml` into the commons-phpmodels declaration DSL under `src/main/resources/models/` (one output file per input file).
- Regenerate with `python3 tools/convert_stubs.py` after any `stubs/` change; generated files carry a `Generated from ...` header and are never hand-edited.
- The converter verifies its own output in-process (re-parse canonicalization, per-kind counts, closed keyword vocabulary) and fails on mismatch.
- `models/` files are committed data only: no Kotlin code reads them and this library has no commons-phpmodels dependency.

# externs-phpstubs

> Read-only lookup of PHP declarations and their value and taint Facts.

## Instructions for Agents

- Use `PhpStubs` for the bundled lookup.
- Use `with` to mount consumer Document Sets without changing the receiver.
- Use `withLibraries` to select available Composer packages.
- Use `matchingFunctions` or `matchingClasses` for canonical literal/gap name queries.
- Match each Fact’s `condition` against the call arguments before applying it.
- Never interpret an absent throws assertion as proof that a call throws nothing.
- Never synthesize host-dependent constant values when `typedSignature.value` is absent.

# Stubs API

> Typed lookup over the mounted Document Sets.

## Quick Start

```kotlin
import edu.jhu.cobra.externs.phpstubs.PhpStubs
import edu.jhu.cobra.externs.phpstubs.callableSignature

val record = PhpStubs.function("strlen")
println(record?.callableSignature?.returnType)
println(record?.sinkFacts)
```

## API

### Construction

- `PhpStubs` and its companion implement `BuiltinLookup`; the companion reads the bundled instance on first access.
- `with(vararg roots: String): PhpStubs` mounts classpath roots after this instance’s sets; the receiver is unchanged.
- `with(vararg dirs: Path): PhpStubs` mounts filesystem directories after this instance’s sets; the receiver is unchanged.
- `libraries: List<LibrarySet>` lists available Composer package metadata; each row has `package: String`, `version: String`, `upstreams: List<String>` and `root: String`.
- `withLibraries(vararg packages: String): PhpStubs` mounts selected generated Library Sets in the supplied order; unknown names raise `IllegalArgumentException`.

### Exact and pattern queries

| Member | Return | Input |
|--------|--------|-------|
| `function(name: String)` | `BuiltinRecord<FunctionSubject>?` | PHP function spelling |
| `clazz(name: String)` | `BuiltinRecord<ClassSubject>?` | Class spelling or a declared class alias |
| `method(spelling: String)` | `BuiltinRecord<MethodSubject>?` | `Owner::name` |
| `method(owner: String, name: String)` | `BuiltinRecord<MethodSubject>?` | Owner and member separately |
| `constant(name: String)` | `BuiltinRecord<ConstantSubject>?` | Global constant spelling |
| `classConstant(spelling: String)` | `BuiltinRecord<ClassConstantSubject>?` | `Owner::NAME` |
| `classConstant(owner: String, name: String)` | `BuiltinRecord<ClassConstantSubject>?` | Owner and member separately |
| `property(spelling: String)` | `BuiltinRecord<PropertySubject>?` | `Owner::$name` |
| `property(owner: String, name: String)` | `BuiltinRecord<PropertySubject>?` | Owner and member separately |
| `variable(name: String)` | `BuiltinRecord<VariableSubject>?` | `$name` |
| `record(subject: ModelSubject)` | `BuiltinRecord<ModelSubject>?` | Declaration/operation subject; class-alias keys are not consulted |
| `matchingFunctions(pattern: NamePattern)` | `Sequence<BuiltinRecord<FunctionSubject>>` | Canonical complete-name pattern |
| `matchingClasses(pattern: NamePattern)` | `Sequence<BuiltinRecord<ClassSubject>>` | Canonical complete-name pattern, excluding alias keys |

- Exact lookup returns null when absent and propagates the subject creator’s `IllegalArgumentException` on validation failure.
- `NamePattern(parts: List<NamePattern.Part>)` accepts `Part.Literal(text: String)` and `Part.Gap`; callers supply PHP ASCII-folded literal text. Each gap accepts any string, including empty, independently.
- `NamePattern.matches(canonicalName: String): Boolean` accepts only the complete spelling, with one optional leading root separator.

### Enumeration and records

- `functions`, `classes`, `methods`, `constants`, `classConstants`, `properties`, `variables`: `Collection<BuiltinRecord<…>>`, each canonical record once in the mount order of its first entry.
- `sinkFacts: List<SinkFact>`, `sourceFacts: List<SourceFact>`, `sanitizerFacts: List<SanitizerFact>`, `flows: List<FlowFact>`, `characters: List<CharactersFact>`, `returns: List<ReturnsFact>`, `throws: List<ThrowsFact>` enumerate Facts in record, Condition, unit and document order.
- `vocabulary: Vocabulary` and `policy: TaintPolicy` expose the accumulated names and policy.
- `BuiltinRecord<S : ModelSubject>` holds `subject: S`, `extension: String?`, `signature: SignatureInfo?`, and the seven Fact lists; `facts: List<Fact>` concatenates returns, flows, characters, sources, sinks, sanitizers and throws in that order.
- `extension` is derived from the mount supplying the effective Signature, or null when that mount does not derive extension metadata.
- `callableSignature`, `classSignature`, `typedSignature`, `propertySignature` are nullable typed extension properties for their applicable record kinds.
- `BuiltinRecord` construction requires a Signature or at least one Fact and requires each Fact’s `owner` to equal `subject`; violations raise `IllegalArgumentException`.

### Fact fields

- Each Fact has `owner: ModelSubject` and `condition: ArgPattern?`. A null `condition` is unconditional. Match a non-null Condition with `matches(actual: List<IPrimitiveVal?>): Boolean?`; a null matching result is undecidable and the caller chooses its applicable rule.

| Type | Additional fields |
|------|-------------------|
| `SinkFact` | `port: Port.Sink`, `vulnType: VulnTypeId` |
| `SourceFact` | `sourceKinds: Set<SourceKindId>`, `at: Port.Argument?`, `keys: List<KeyPattern>?` |
| `SanitizerFact` | `vulnTypes: Set<VulnTypeId>`, `check: ArgumentCheck?` |
| `FlowFact` | `from: Port.Input`, `to: Port` |
| `CharactersFact` | `bound: CharacterBound` |
| `ReturnsFact` | `kind: ReturnKind` |
| `ThrowsFact` | `classes: Set<ClassSubject>` |

- `VulnType` enumerates `sqli`, `cmdi`, `codei`, `xss`, `headeri`, `ssrf`, `pathtrav`, `fileinc`, `deser`, `callablei`, `ldapi`, `xpathi`, `schemei`, `openredirect`, `nosqli`, `templatei`; `id: VulnTypeId` is its typed name.
- `SourceKind` enumerates `user-input`, `external-input` and `server-path`; `id: SourceKindId` is its typed name.
- A consumer-added name can be compared by its typed identifier without a library enum constant.

### Resource API and errors

- `StubResources.MODELS`, `VALUE_RULES`, `VOCABULARY`, `TAINT`, `TAINT_RULES` and `PSALM_MAPPING` name the bundled resources.
- `StubResources.opener(root: String): ResourceOpener` opens a relative path under the classpath root and returns null for an absent resource.
- `StubIndexNotFoundException` reports a missing manifest, listed document, catalog or mapping resource.
- `StubIndexInvalidException` reports a malformed set/catalog, missing required provenance, generated-set violation, conditional Signature or colliding class-alias key; the cause retains format failure details.

## Configuration

- Supply consumer roots holding `index.txt`; the listed documents follow the dependency-owned Document Set format. Without provenance a consumer set mounts as manual.
- Select exact names from `PhpStubs.libraries`; selection does not infer an installed version from `composer.lock`.
- Use `PhpStubs.withLibraries("laravel/framework")` for bundled package data and apply later manual corrections with the returned lookup’s `with` methods.

## Gotchas

- Functions, classes and methods fold ASCII case. Global constants retain case except root `TRUE`, `FALSE`, `NULL`, whose case variants identify the same Matching Subject.
- Declaration existence is `signature != null`; a Fact-only record does not prove a declaration exists.
- A null `typedSignature.value` means the declaration supplies no concrete value; `PHP_INT_MAX` is such a constant.
- `filter_var` has five conditional sanitizer Facts and no unconditional sanitizer Fact.
- A Value unit couples `returns`, `flows` and `characters`; select them under the same Condition.
- An empty `ThrowsFact.classes` asserts no throws within the format boundary; an absent ThrowsFact asserts nothing. The [indirect-call extraction gap](../design-extraction.md#open-gaps) remains uncorrected.
